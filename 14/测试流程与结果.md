# Socket 项目测试流程与结果

## 1. 测试目标

- 验证项目1多播文件分发可运行。
- 验证项目2 TCP 与 UDP 大文件传输可运行并输出速率。
- 检查发送前后文件大小是否一致。

## 2. 测试环境

- 操作系统: Windows
- 工作目录: D:/大二下/计算机网络/homework/CNhomework
- 代码目录:
  - 14/project1_multicast
  - 14/project2_tcp_udp

## 3. 操作流程

### 步骤A: 准备测试文件

1. 进入 14 目录。
2. 生成 50MB 测试文件 test_50mb.bin。

### 步骤B: 项目1 多播测试

1. 在 project1_multicast 启动接收端 receiver1。
2. 可选启动 receiver2，验证一发多收。
3. 在同目录启动发送端 sender，发送 test_50mb.bin。
4. 记录 sender 与 receiver 输出的耗时、速率。
5. 对比 test_50mb.bin 与接收文件大小。

### 步骤C: 项目2 TCP 测试

1. 在 project2_tcp_udp 启动 tcp_server。
2. 启动 tcp_client 发送 test_50mb.bin。
3. 记录 client 与 server 输出的耗时、速率。
4. 对比发送文件与接收文件大小。

### 步骤D: 项目2 UDP 测试

1. 在 project2_tcp_udp 启动 udp_server。
2. 启动 udp_client 发送 test_50mb.bin。
3. 记录 client 与 server 输出的耗时、速率。
4. 对比发送文件与接收文件大小。

### 4.1 文件完整性对比

| 模式 | 源文件字节 | 接收文件字节 | 是否一致 |
|---|---:|---:|---|
| Multicast receiver1 | 52428800 | 52428800 | 是 |
| Multicast receiver2 | 52428800 | 52385400 | 否 |
| TCP | 52428800 | 52428800 | 是 |
| UDP | 52428800 | 12345344 | 否 |

### 4.2 速率结果

| 模式 | 发送端速率 MB/s | 接收端速率 MB/s | 备注 |
|---|---:|---:|---|
| Multicast | 25.03 | receiver1: 0.40, receiver2: 0.44 | receiver2 出现丢包告警 |
| TCP | 186.57 | 187.27 | 本机回环链路，完整接收 |
| UDP | 279.33 | 未输出最终汇总 | 服务端出现大量丢包，结束包可能丢失 |

## 5. 结论

- 项目1与项目2均已按流程执行测试。
- 多播与 UDP 都出现了不同程度丢包，这是本次“简化模拟且无重传机制”的预期现象。
- TCP 在本机测试中完整性最好，速率稳定且接收完整。
